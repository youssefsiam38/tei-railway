# Assets

`icon.png` is a 512x512 mark drawn for this template: words becoming a grid of numbers, and those
numbers becoming points in a space, which is what an embedding model does. It was made in `PIL` for
this repository and is MIT licensed along with the rest of it.

Nothing from Hugging Face or the Text Embeddings Inference project is reused, and neither is
affiliated with or endorses this template.
